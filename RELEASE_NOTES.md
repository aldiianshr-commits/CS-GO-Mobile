## CS:GO Mobile — build uji

APK native Android (arm64-v8a, Android 10+, Vulkan) yang membaca file asli **Counter-Strike: Global Offensive Xbox 360** milik Anda dari `/storage/emulated/0/CSGO/` dan merender petanya dengan engine sendiri (tanpa emulator).

**Instal:** unduh `CSGO-Mobile.apk` → buka → izinkan "Instal aplikasi tidak dikenal" → buka aplikasi → *Izinkan akses file* → salin paket XBLA/ISO/folder CS:GO Xbox 360 ke `/storage/emulated/0/CSGO/` → *Pindai ulang* → pilih peta.

**Yang bisa dilakukan:** menjelajah peta CS:GO 360 (tekstur, lightmap, displacement, skybox) dengan gerak & kolisi FPS, kontrol sentuh/gamepad/keyboard, simpan/muat posisi di `/CSGO/saves/`, semua pengaturan grafis + preset, driver Turnip opsional.

**Belum:** senjata, bot, ronde, model/props, audio, multiplayer (kode game PowerPC asli tidak dijalankan).

Lihat README untuk detail, pengaturan, driver Turnip, dan batasan teknis.
